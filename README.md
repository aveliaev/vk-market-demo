# VK Оплата

[Открыть демо-маркет](https://aveliaev.github.io/vk-market-demo/)

Выберите товар, положите его в корзину и пройдите тестовую оплату. Доступны роли покупателя и продавца. Публичное демо хранит данные в этом браузере через IndexedDB и SQLite. Каждый посетитель начинает с отдельного демо-магазина. Деньги не списываются.

Локальная версия использует Node.js и SQLite. Для локального запуска установка npm-пакетов не требуется.

## Запуск

Нужен Node.js 22.13 или новее.

```sh
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сервер слушает только локальный адрес. База создаётся в `data/vk-demo.sqlite`. Переменная `PORT` меняет порт, `VK_DEMO_DB` задаёт путь к другой базе.

## Сценарий для защиты

В демо самовывоз из мастерской бесплатный. При оформлении покупатель выбирает день и интервал самовывоза либо один из двух демонстрационных пунктов выдачи за 290 ₽. Для индивидуального заказа срок получения в пункте выдачи составляет 2–4 дня после передачи готового изделия. Стоимость доставки включается в оплату, чек и возврат.

Для демонстрации корзины добавьте вазу «Орбита» за 3 200 ₽ и две кружки «Утро» по 1 200 ₽ при исходных ценах. В корзине можно поменять количество каждого варианта и удалить позицию. Оформите заказ на 5 600 ₽ и оплатите его одним тестовым платежом. В чеке будут обе позиции. Отметьте заказ готовым в реестре продавца и откройте «Мои заказы» в том же браузере, чтобы увидеть обновлённый статус. История и корзина привязаны к cookie профиля браузера.

В «Аналитике» воронка считает уникальные браузеры на каждом этапе с момента включения учёта. Прямая покупка позволяет сразу перейти к оформлению. Для заказов из переписки отдельно показаны количество отправленных и оплаченных заказов и число покупателей, дошедших до оформления и оплаты.

1. Откройте десктопный каталог, найдите кружку «Утро» через поиск и откройте её карточку. Выберите две кружки за 2 400 ₽ и нажмите «Купить». На оформлении откройте «Сравнить с оплатой в чате». В показанном магазине VK заказ уже создаётся и попадает в чат с номером, ссылкой и суммой товара. Стоимость и срок доставки и порядок оплаты покупатель уточняет в переписке. В MVP для готового товара на оформлении видны варианты получения, сумма и три способа оплаты. Выберите карту, подтвердите тестовый платёж и откройте чек.
2. В разделе «Заказы» откройте созданный заказ. Проверьте комиссию VK 36 ₽, эквайринг по карте 48 ₽ и сумму к выплате 2 316 ₽. Отметьте готовность, выдачу и перечисление.
3. В разделе «Подключение» нажмите «Пройти подключение заново» и выберите «Пока нет статуса». Укажите собственное производство и соответствие ограничениям НПД. Пройдите тестовую регистрацию, вернитесь в магазин и включите выплаты и чеки. Получите тестовый ответ партнёра.
4. В разделе «Цена и комиссии» введите 1 000 ₽. Цена покупателя составит 1 015,23 ₽. Кабинет рассчитает эквайринг по карте и СБП отдельно. Кнопка «Сохранить цену» обновляет витрину, сумма уже созданного заказа сохраняется.
5. Откройте тарелку «Спираль», нажмите «Обсудить заказ» и отправьте сообщение. На витрине и в карточке указан максимальный срок изготовления — до 2 недель. В переписке продавец согласует дату и отправляет заказ на оплату. Выберите VK Кошелёк, чтобы увидеть демо-кешбэк 5%. За тарелку стоимостью 1 850 ₽ он составит 92,50 ₽. Для проверки отмены можно закрыть неоплаченный заказ.
6. Для возврата откройте оплаченный заказ со стороны покупателя и отправьте запрос. Подтвердите полный возврат в кабинете продавца. После ответа партнёра на заказе появятся статусы возврата и корректировки чека.
7. В аналитике проверьте долю внутренних оплат и экономику. Внесите внешние продажи и расходы для пересчёта. В административном разделе проверьте журнал событий и сверку сумм.

## Данные и платёжный контур

В демо-магазине есть история заказов вымышленных покупателей, отзывы и ответы мастерской. Две покупки демопрофиля видны в публичной версии в разделе «Мои заказы». Отметка о друзьях на кружке «Утро» основана на демонстрационных покупках. Для быстрого показа все роли доступны в одном интерфейсе. Покупательская ссылка использует случайный токен. Оплата, проверка НПД, чек, выплата и возврат имитируются локально. Ввод номера карты и персональных сведений отсутствует.

Комиссия VK в модели составляет 1,5%. Эквайринг принят за 2% для карты, 0,7% для СБП и 0% для тестового кошелька. Демо-кешбэк рассчитывается от суммы оплаты с округлением до копейки. Сумма списания и выплата продавцу рассчитываются по полной цене. В расчётах полного возврата комиссия VK возвращается, эквайринг удерживается. Условия используются для демонстрации и сверяются с партнёром перед реальным пилотом.

Для реального пилота нужны участие VK, доступ к одному платёжному партнёру, подтверждённые договором тарифы и схема НПД, выдача чеков, а также аутентификация и авторизация по ролям и магазинам.

## Проверка

```sh
npm test
```

Тесты используют временную базу и проверяют отбор продавца, цену, повторные запросы, восстановление платежа после перезапуска, чек, выплату, возврат, оплату из чата и просрочку.

## Посты магазина

Раздел «Создать пост» предлагает прикрепить готовый товар при подключённой оплате. Пост сохраняется в демо-магазине и появляется под каталогом. В публичной версии данные доступны в текущем браузере.

Аватарка `public/assets/shop-avatar.png` создана встроенным ImageGen. Запрос описывает светлую керамическую вазу в форме органичной буквы f на терракотовом фоне, с запасом по краям для круглого кадрирования.

## Публикация

GitHub Actions проверяет тесты, собирает сайт и публикует изменения из ветки `main` на GitHub Pages. Для самостоятельной сборки выполните `npm ci` и `npm run build:pages`. Каталог `dist` можно раздавать по HTTPS.
